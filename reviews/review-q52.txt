——**液态玻璃：按 shuding/liquid-glass 的位移剖面重做玻璃主题**

## 0. 用户的话

「灵动岛 我想要液态玻璃的效果 https://github.com/shuding/liquid-glass 可以参考参考这个」

当前玻璃主题已经有真实折射链（WGC 抓岛下方窗口 + CPU 位移 + D2D 画回胶囊），
不是从零开始。这一轮只讨论**折射的几何 + 调色 + 内侧体积**，不讨论捕获路线、
不加窗口、不回到"模糊膜"（用户已经明确否掉"雾蒙蒙"）。

## 1. 参考实现（liquid-glass.js，MIT）到底做了什么

一个 300x200、border-radius 150px 的元素，`backdrop-filter` 引用 SVG：
`feImage`（画布生成的位移图）+ `feDisplacementMap`（R/G 通道）。位移图逐像素生成：

```
ix = uv.x - 0.5;  iy = uv.y - 0.5;
d    = roundedRectSDF(ix, iy, 0.3, 0.2, 0.6);
disp = smoothStep(0.8, 0, d - 0.15);
s    = smoothStep(0, 1, disp);
sample = (ix * s + 0.5, iy * s + 0.5);
```

即：**中心一块完全不位移（s=1）**，越靠近边缘采样点越向中心收（压缩），
是一条 SDF 驱动的平滑剖面；不是"边缘一条窄带"，也不是"越靠边越向外拉"。

按 JS 公式算（不是实测）：300x200 上 d≤0.15 的"不位移区"约 **201x115 px
（67% 宽 × 57.5% 高）**；每侧过渡带约 **50px 横 / 43px 纵（17% / 21%）**。
边缘中点位移：右缘 **3.2px**、下缘 **6.4px**；角的原始位移约 97x65px，
但位移图按 max 归一化后会被 8-bit 截断，实际最大约 **24px**。
所以这个材质的观感是：**中间大块是平的，弯的只是边缘，而且圆角/角部比直边弯得多**。

叠加的 CSS：

```
backdrop-filter: url(#f) blur(0.25px) contrast(1.2) brightness(1.05) saturate(1.1);
box-shadow: 0 4px 8px rgba(0,0,0,.25), 0 -10px 25px inset rgba(0,0,0,.15);
border-radius: 150px;
```

没有独立的 rim / specular / 色散；"厚度"来自**内侧阴影 + 位移梯度**。
可拖动只是 demo 交互，片元没有用指针；静息态就是最终材质。

## 2. 我们现在的实现（同一类，不同参数）

- 捕获：WGC 抓"岛下方那个窗口"（桌面时是 Progman），30Hz；镜头 80ms 更新（上限 12.5Hz）。
- 位移：对胶囊每个输出像素求到边界的距离 `inside`：

```
t = inside / 26px;
shift = (1-t)^2 * 22px;   shift *= 1 + 0.35*|nx|;
sample = p + n*shift + (0, -(py-cy)*1.5*(1-nyN^2));
```

即：26px 带、最大 22px、**向边缘外扩**；圆端 +35%；另加一个全高桶形项。
- 调色：对比度 1.08 / 亮度 1.02 / 饱和度 1.08；无模糊。
- 主题：胶囊填充 alpha 0；rim 0；shadow 0；gloss .20；sweep .55；grain .03；tint .25；近黑字。
- 实测：镜头更新 0.36ms（10-17；现在多了 grade，量级不变）；空闲重绘 11.5 帧/秒，
  帧均 10~11ms，>50ms 卡顿 0。截图 `captures/no-outline.png`、`captures/grade.png`。
- 约束：单 exe、静态 CRT、零第三方依赖、无新窗口/线程；/WX；空闲 CPU 要低。

## 3. 一个具体的当前缺陷（这轮要一起修）

现在的映射在**胶囊垂直中线**上不连续：

- 直边段的法线 `ny` 在中线从 -1 翻成 +1，而中线处 `shift` 仍有约 2.1px；
- 附近几行的采样 y（用代码公式算）：
  `py=15 -> 15.44`, `16 -> 15.71`, `17 -> 15.86`, `18 -> 20.08`, `19 -> 20.14`；
- 也就是 17→18 这一行，采样点跳了 **4.2px**；上半边几乎被压平（0.15~0.27px/行），
  然后突然跳过去。高对比条纹/文字背景上会读成一道横向折痕。
- 桶形项 `lensY` 还把中心区压成近似不动、边缘再拉伸，和参考的"中心平、边缘弯"
  正好相反。

参考的 SDF 剖面在中心 `shift=0`，所以中线的法线翻转不会产生跳变；这是我认为
应该换剖面的主要理由（不只是审美）。

## 5. 问题（请逐条明确表态，不要只列选项）

**Q1. 参考的"液态感"主要来自哪一层？** 按重要性排序：平中心 + 窄过渡带 /
角部强弯 / 调色 / 0.25px 模糊 / 内侧阴影。如果只能做一件，做哪件？

**Q2. 220x36 上怎么缩放？** 参考的 300x200 是我们的 5.5 倍高：
- 按半高归一化：过渡带 7.7px、边缘位移 1.15px；会不会太弱、根本看不见？
- 按绝对像素：保留 22px 位移但把带收窄到 8~10px；会不会又变成"折纸"？
- 还是混合：直边 6~8px 带、位移 3~5px；圆端 18~24px 位移、带 12~16px？
请给一组你们认为在 1x 下能读成"玻璃"、又不把日期/时间背景压变形的数字。

**Q3. 采样方向选哪个？** 参考向中心压缩（内采），我们现在向边缘外扩（外采）。
外采需要在胶囊外留 32px 余量（现在就是），内采可以只留几像素、还能避开屏幕顶边
抓不到背景的问题；但内采在圆端会把内容放大/挤压。对 220x36 的胶囊，你们选哪个？
能不能外采 + 内采组合而不出现接缝？

**Q4. 角部截断。** 参考的位移图把角部原始 97px 截到约 24px；我们的上限是 32px
余量/22px 位移。要不要保留这个截断？上限取多少（按高度百分比还是固定 DIP）？

**Q5. 内侧阴影。** 它和用户已经否掉的"轮廓/亮边"是不是同一类东西？
36px 高上等效参数大概是多少（y 偏移、blur、alpha）？会不会又把岛变成"有边"？

**Q6. 调色与模糊。** 参考的 1.2/1.05/1.1 是在 sRGB 上做的；我们的逐通道 grade
也是 sRGB。直接照搬对吗，还是应先转线性光？0.25px 模糊在 1x/bilinear 下有意义吗，
值得加 3-tap 吗？

**Q7. 顶边抓取。** 岛在屏幕顶边，胶囊上方 32px 永远抓不到，现在用"复制最近一行"补。
参考没有这个问题。改成内采后这条补边是否还需要？如果保留外采，新的强位移会不会
把补边放大成一条可见的带？

**Q8. 验收。** 给"一个数字 + 一行日志"。候选：中心位移 ≤1px；边缘位移 ≥6px；
竖直中线相邻两行采样差 ≤0.5px（修掉 4.2px 跳变）；镜头更新 ≤0.6ms；空闲重绘不变；
自检 0 失败。你们会怎么量、阈值取多少？

**Q9. 有没有哪一部分是我们不该照搬的？**（拖动、backdrop-filter 的 DOM 语义、
300x200 的固定 SDF、角部截断……）
